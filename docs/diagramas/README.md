# Diagramas de arquitectura WOKI

- `woki-arquitectura.drawio`: fuente editable con tres páginas.
- `woki-arquitectura-sistema.svg`: lámina vectorial del sistema completo.
- `woki-arquitectura-sistema.png`: exportación para presentaciones.

La fuente técnica detallada permanece en [`../ARQUITECTURA-CONEXIONES.md`](../ARQUITECTURA-CONEXIONES.md).

## Editar

Abre el archivo `.drawio` en <https://app.diagrams.net> o draw.io Desktop. Las imágenes 3D necesarias están embebidas, así que el archivo no depende de rutas locales.

Páginas:

1. Sistema completo.
2. Conexiones físicas y energía.
3. Módulos de software y seams.
